Скопируйте `issue.example.json` в `content/YYYY-MM-DD.json`, замените поля. В `body` доступны блоки:
`<article class="lead">` (главный, фото слева), `<article class="feature">` с `<div class="cols">`, `<div class="grid">` с `<article class="note">`,
`<section class="rubric">` (рубрики), `<p class="kicker">`, `<p class="op">` (мнение редакции), `<p class="src">` (источники), `<ul class="facts">`.
Пути к картинкам: `{{ROOT}}assets/img/имя.jpg`.

Порядок рубрик в номере (пример — `issue.example.json`): Главное → Большой материал → Статья arXiv недели → Цифры недели → заметки (grid) →
Наука в России + Хорошие новости из России (grid из двух `note`) → Кадр недели (`rubric` с `figure`) → ИИ‑инструмент недели → Мысленный эксперимент →
Идея недели → Что почитать и посмотреть. «Было/стало» (в каждом номере) — `<section class="rubric">` с `<p class="kicker">Было/стало</p>` и списком
`<ul class="facts"><li><strong>Было:</strong> … → <strong>Стало:</strong> … <a>источник</a></li></ul>`, ставить после «ИИ‑инструмента недели».
В `items` для каждого материала указывать `rubric`, `title`, `source`, `event_date`.
Не добавлять в шаблоны ссылки на `issues.json` для читателя — файл служебный.

Навигация генерируется `build.py`: ссылки на архив и PDF в теле номера не добавлять (они в шапке), внизу/вверху — только ←/→ между номерами.

## Еженедельный номер (с № 14)
Поля: `"kind": "weekly"`, `"week": ["ПН", "ВС"]` (ISO-даты), `date` = воскресенье, `publish_at` = `<воскресенье>T21:00:00+03:00`.
Подпись номера строится сама: «№ 14 · 2–8 ноября 2026». Оглавление (сайт и обложка PDF) собирается автоматически из
`<section class="part" data-part="Работа|Жизнь">`, заголовков `<h2>` и кикеров рубрик. Скелет `body`:
`lead` (обложка) → `rubric` «Неделя за 5 минут» → `<section class="part" data-part="Работа">` (2–3 `feature` + рубрики Работы)
→ `<section class="part" data-part="Жизнь">` (2 `feature` + рубрики Жизни). В PDF каждая часть и каждый `feature` начинаются с новой полосы.
